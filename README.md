# Vila+Saúde — UI

Interface do projeto acadêmico Vila+Saúde (Grupo 03, UESPI/UAPI).

Arquivos: `index.html`, `app.js`, `style.css`, `favicon.svg`.

**Atenção:** a interface foi separada do repositório original, mas ainda usa chamadas relativas a `/api`. Para hospedagem independente, será necessário configurar a URL da API, CORS e sessão/cookies ou um proxy de mesmo domínio. A implantação funcional permanece no repositório original.

Use somente dados fictícios. Não é um sistema homologado para pacientes reais.
